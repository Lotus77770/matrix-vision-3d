# 线性变换可视化 — 需求与分阶段验收方案

> **v1 已实现（2026-10-10）**：本文档描述当前版本（第一版）的需求与分阶段验收方案，**内容与代码现状一致**。
> 功能总览见 [README.md](../README.md)；版本变更见 [CHANGELOG.md](../CHANGELOG.md)。

> 目标：用 three.js 做一个页面，把「3×3 矩阵对基向量（及空间网格）的线性变换」直观地演示出来，
> 并且能一边在控制台调整矩阵数值、一边实时看到场景变化。

---

## 一、技术栈

| 项 | 选择 | 说明 |
| --- | --- | --- |
| 构建 | **Vite 8** | 开发热更新，产物可部署 |
| 3D 库 | **three.js（npm 安装）** | 依赖本地化，离线可用 |
| 语言 | JavaScript | 未使用 TypeScript |
| 单文件交付 | **vite-plugin-singlefile** | 构建时把 JS / CSS 内联进 HTML，产物为自包含的单文件 |
| 运行时依赖 | **仅 three** | 刻意保持零额外运行时依赖 |

验收方式：`npm install` → `npm run dev`，浏览器打开本地地址自行查看；或 `npm run build` 后 `npm run preview` 查看构建产物（单文件 `dist/index.html`）。

## 二、场景内容规格

### 1. 空间与背景
- 纯黑背景的三维空间。
- 透视相机，初始以斜视角看向原点。

### 2. 坐标轴（三条，互相垂直）
- 从原点出发指向各自正方向，**白色数轴**，半长 **±4**。
- **不显示任何数字**。
- 在**整数刻度位置**用**白色垂直线段**（短刻度线，垂直于该轴本身）标记。
- 三条轴的两端各有 `+X / -X / +Y / -Y / +Z / -Z` 标签（Sprite，始终正对相机，便于阅读）。

### 3. 向量列表（默认含 3 个基向量）
- 控制台内维护一个**向量列表**，**默认包含三个基向量** e₁、e₂、e₃（分别指向 x、y、z 轴正方向，颜色各异）。
- 列表中的每个向量都可**添加 / 删除 / 修改坐标 / 设置颜色**（含默认基向量，允许全部删除）。
- 向量以**带箭头的实体**（圆柱 + 圆锥箭头）渲染，**粗大、醒目**，明显比坐标轴线和网格线粗。
- 单位矩阵下长度为 **1**；施加矩阵后画面显示的是 **M·v**，长度与方向随之变化。

### 4. 空间网格
- **三维立方格阵**：在 x、y、z 三个方向上都按 1 单位间隔排布的立体格子线。
- 范围 **±3**（每个方向 -3 到 3，含 0），每 1 单位一条线，共 147 条长线。
- 颜色比坐标轴与向量更暗，作为背景参考，不与主体抢视觉。
- 可按 **x / y / z 三个方向独立显隐**（仅影响显示，不影响变换结果）。

## 三、交互规格

- **单画面，无状态切换**：三维场景**始终全屏**显示，不再有「控制台 / 场景」两种状态的来回切换。
- **控制台**是浮在场景**左上角**的卡片面板，可**折叠为一个按钮**（收起后只剩左上角一个图标按钮，场景不被遮挡）。
- 控制台内含：
  - **3×3 矩阵**：每个元素都可改数值——既可以**输入框设置**，也可以**拖动滑块**调整，改动实时作用于场景。
  - **向量列表**：每行可改**颜色**、改**坐标**、**删除**；底部有「**添加向量**」按钮。
  - **网格线显示**：X / Y / Z 三个方向的网格线**独立开关**。
  - **「重置为单位矩阵」按钮**：恢复单位矩阵，并把**相机视角一并复位到初始状态**。
- **视角操作**：
  - `Alt` + 鼠标拖拽 —— 旋转视角
  - `Alt` + 滚轮 —— 缩放
  - `W` / `A` / `S` / `D` —— 前后左右移动
- **悬停提示**：鼠标指向任一向量时，在鼠标旁浮出它**变换后的坐标**；移开即自动隐藏。

---

## 四、关键注意点
1. **实时联动**：在控制台调节矩阵数值时，场景中的变换结果要同步实时变化。
2. **向量要不同颜色且粗大明显**。
3. **坐标轴为白色、无数字**，整数位置用**白色垂直线段**标记。
4. **变换范围**：矩阵同时作用于**向量列表中的所有向量**和**整个立方格阵**（网格随之被拉伸 / 剪切）。
5. **不保留**原始（未变换）的向量，画面上只显示变换后的结果。

---

## 五、数学约定
- 记矩阵 M（3×3），空间中任一点 / 向量 **v** 变换后为 **M·v**。
- 默认基向量 e₁=(1,0,0)、e₂=(0,1,0)、e₃=(0,0,1) 变换后即为矩阵的三列。
- 网格所有顶点同样按 **M·v** 变换，因此网格整体被线性变换。
- 默认矩阵为**单位矩阵**，此时画面等于未变换状态。

## 六、分阶段验收方案

### 阶段 1 — 工程骨架 + 静态场景
实现内容：Vite + three 初始化；黑色空间；三条白色坐标轴（含整数刻度与轴端标签）；3 个彩色粗基向量；±3 三维立方格阵；视角操作（Alt+鼠标、Alt+滚轮、WASD）。

验收清单：
- [x] `npm install` 与 `npm run dev` 均无报错，页面正常打开
- [x] 背景为纯黑
- [x] 三条互相垂直的白色坐标轴，且**没有任何数字**
- [x] 每个整数位置都有白色短竖线刻度
- [x] 三个基向量颜色各不相同，粗大醒目，初始长度为 1，分别指向 x/y/z 正方向
- [x] 存在 ±3 的三维立方格阵，颜色比向量和坐标轴暗
- [x] `Alt` + 鼠标拖拽可旋转视角
- [x] `Alt` + 滚轮可缩放
- [x] `W`/`A`/`S`/`D` 可前后左右移动
- [x] 改变浏览器窗口大小，画面不变形

### 阶段 2 — 矩阵控制台 + 实时联动
实现内容：3×3 矩阵 UI（每格输入框 + 滑块）；浮在场景左上角的控制台面板（可折叠）；矩阵实时作用于向量与立方格阵。

验收清单：
- [x] 控制台内有 3×3 矩阵，9 个元素各有输入框和滑块
- [x] 拖动滑块或输入数值，向量与立方格阵按 M·v **实时**变换
- [x] 默认单位矩阵时，画面与阶段 1 一致
- [x] 控制台浮在场景左上角，可**折叠为一个按钮**
- [x] 数值正确性抽查（例：M = diag(2,1,1) 时，x 向向量长度变为 2；M 含非对角项时网格出现剪切）

### 阶段 3 — 打磨与细节 + 扩展
实现内容：视觉与交互细节、向量列表、悬停坐标、数值边界、性能与适配。

验收清单：
- [x] 配色、线宽、刻度长度整体观感协调（向量最醒目 > 坐标轴 > 网格）
- [x] 矩阵数值范围与步进合理（-3 ~ 3，步进 0.1）
- [x] 缩放 / 旋转 / 移动过程流畅，无明显掉帧
- [x] 高分屏（devicePixelRatio）下线条清晰不糊
- [x] 控制台浮层与三维场景互不干扰（窄窗口下控制台内部可滚动）
- [x] 坐标轴两端 `+X/-X/+Y/-Y/+Z/-Z` 标签随视角始终正对相机
- [x] 向量列表：可添加 / 删除 / 修改坐标 / 设置颜色
- [x] 网格线三向独立显隐
- [x] 鼠标悬停向量时显示其变换后的坐标
- [x] 「重置为单位矩阵」同时复位相机视角

## 七、已定结论（原「待定项」）
1. 矩阵元素的**取值范围与步进**：-3 ~ 3，步进 0.1。
2. 提供「**重置为单位矩阵**」按钮，并同时复位相机视角。
3. **不额外显示**坐标数值标签；改为**鼠标悬停向量时**在鼠标旁显示其变换后坐标。
4. 坐标轴半长 **±4**，整数刻度线长 0.2。
5. 相机**初始视角**：环绕原点、距离 9.5、方位角 π/4、极角 1.15（见 `CONFIG` / `DEFAULT_VIEW`）。
6. **不改用 TypeScript**，保持原生 JavaScript。
