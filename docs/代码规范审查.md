## 二、P0 — 明文违反 `AGENTS.md`

### P0-1 CSS 只令牌化了颜色，圆角 / 间距 / 动效未令牌化

`AGENTS.md` 要求：「界面（CSS）的颜色、**圆角、间距**统一用 `:root` 自定义属性」。实际 [`src/style.css`](../src/style.css) 的 `:root` 内只有 `--color-*` 一组。

实测散落的硬编码：

| 项 | 数量 | 取值 |
| --- | --- | --- |
| `border-radius` | 12 处 | 4 / 5 / 6 / 7 / 8 / 9 / 12 / 16 / 999px 共 9 种 |
| `transition` | 9 处 | 时长仅 `0.15s` / `0.2s` 两种，却在各处重复书写完整属性列表 |
| `outline: 2px solid var(--color-accent-focus)` | 3 处 | 焦点环完全重复 |
| 间距（`gap` / `padding` / `margin` / `top/left`） | 全篇 | 无任何令牌，纯裸数值 |

改进方向：在 `:root` 增补 `--radius-sm/md/lg/pill`、`--space-*`、`--dur-fast/--dur-base`、`--ease`，并把焦点环合并为一条共享规则（如 `:where(button, input):focus-visible { outline: var(--focus-ring) }`）。

### P0-2 3D 世界参数未全部收敛到 `CONFIG`

`AGENTS.md` 要求 `CONFIG` 是「几何尺寸、颜色、取值范围的唯一来源」。

未进 `CONFIG` 的可调参数：

| 参数 | 现值 | 位置 |
| --- | --- | --- |
| 相机 fov / near / far | `50` / `0.1` / `500` | [main.js](../src/main.js#L46) |
| 环境光颜色 / 强度 | `0xffffff` / `0.75` | [main.js](../src/main.js#L49) |
| 主光 / 补光强度 | `1.0` / `0.35` | [main.js](../src/main.js#L50-L55) |
| 控制器 `minRadius` / `maxRadius` | `1.5` / `60` | [main.js](../src/main.js#L339-L340) |
| 控制器 `rotateSpeed` / `zoomSpeed` / `moveSpeed` | `0.006` / `0.0015` / `3.5` | [main.js](../src/main.js#L341-L343) |
| 极角夹取边界 | `0.05` / `Math.PI - 0.05` | [main.js](../src/main.js#L381-L385) |
| 轴标签画布尺寸 / 字号 / 颜色 | `128` / `84px` / `#ffffff` | [main.js](../src/main.js#L61-L71) |

其中轴标签的 `#ffffff` 是 3D 世界里的文字颜色，按约定也应与 `CONFIG.color.axis` 同源。

### P0-3 `#viewport` 由 JS 搬进 `#stage`，标记结构与运行时不符

[index.html](../index.html#L10-L13) 中 `#viewport` 与 `#stage` 是**兄弟节点**，靠 [main.js L746](../src/main.js#L746) 的 `stage.appendChild(viewport)` 在运行时搬家。

约定的描述是「`#viewport` 始终位于全屏 `#stage` 中」。现状带来两个隐性依赖：

1. JS 未执行（加载失败 / 被禁用）时，布局与运行时不同；
2. `resize()` 与 `ResizeObserver` 的有效性隐式依赖 `appendChild` 先于它们执行。

改进方向：HTML 直接把 `#viewport` 嵌套进 `#stage`，删掉 `appendChild` 一行。

## 三、P1 — 重复模式与真实缺陷（"越改越乱"的源头）

### P1-1 矩阵 × 向量公式写了两遍

同一公式出现在 [`applyMatrix` 向量分支 L289-293](../src/main.js#L287-L295) 与 [网格分支 L301-309](../src/main.js#L298-L310)。任一处改动而漏掉另一处，就会出现「箭头对了、网格错了」这类难查问题。

改进方向：抽 `transformPoint(e, x, y, z, out)`（或 `applyToXYZ`），两处共用一份实现。

### P1-2 两套 `identity`，命名几乎相同

[`identityMatrix`](../src/main.js#L280) 是 `THREE.Matrix3` 单位矩阵，[`identity`](../src/main.js#L465-L470) 是 `[[1,0,0],[0,1,0],[0,0,1]]` 数组。二者名字相近、语义不同，极易混用。

改进方向：`IDENTITY_MAT3` / `IDENTITY_VALUES`，并让后者由前者派生，避免两处手工维护。

### P1-3 折叠小节类名不统一，样式一字不差地重复

| 位置 | 类名 | 职责 |
| --- | --- | --- |
| [index.html L47](../index.html#L47) | `.vector-section` | 整节容器（按内容命名） |
| [index.html L76](../index.html#L76) | `.grid-toggles` | 整节容器（按控件命名，但真正的开关是里面的 `.grid-toggle`） |

两者的分隔样式 [style.css L286-290](../src/style.css#L285-L290) 与 [L348-352](../src/style.css#L347-L352) 完全相同（`margin-top: 16px; padding-top: 14px; border-top: 1px solid var(--color-divider)`）。

改进方向：抽公共基类 `.section`，两者都改成 `.section` + 修饰类；新增第三个折叠小节时就不会再复制一遍。

### P1-4 删除向量不释放几何体与材质（GPU 内存泄漏）

[删除逻辑 L650-L656](../src/main.js#L645-L657) 只做 `scene.remove(entry.arrow)`。每个箭头独占 `CylinderGeometry` + `ConeGeometry` + `MeshStandardMaterial`（[createVectorArrow L199-L233](../src/main.js#L199-L233)），不移交 `dispose()` 就会持续占用显存。

改进方向：删除时遍历箭头子节点，对其 `geometry.dispose()`，并对共享材质 `dispose()` 一次。

**运行时已证实**（headless Chrome + WebGL2）：`renderer.info.memory.geometries` 初始 15 → 添加向量后 17 → 删除该向量后仍为 17，未回落；`textures` 全程不变（7）。即每次「添加再删除」净泄漏 2 个几何体。

### P1-5 颜色有两份状态

`addVector` 把 `color` 存进 `entry.color`（[L264](../src/main.js#L264)），颜色输入框也会更新 `entry.color`（[L619](../src/main.js#L619)），但渲染与改色实际走 `entry.arrow.userData.material`。两份状态目前恰好一致，一旦有人从代码里改颜色就会分叉。

改进方向：以 `entry.color` 为唯一真源，改色时统一走一个 `setVectorColor(entry, hex)`。

### P1-6 纯包装、无任何样式的类

`section-toggle-title`（[index.html L54](../index.html#L54)、[L83](../index.html#L83)）与 `name`（[L103](../index.html#L103)、[L107](../index.html#L111)）在 CSS 中**零规则**，属于空壳标记。

同类还有 `.num` / `.rng`：JS 在创建矩阵控件时给输入框设了 `className = 'num'` / `'rng'`（[main.js L502](../src/main.js#L502)、[L511](../src/main.js#L511)），但 CSS 完全靠 `.cell input[type="number"]` 这类属性选择器取样式，这两个类名从未被任何规则引用。

改进方向：要么补上规则（让类名成为真正的样式钩子），要么删掉这两个 `span` 与 `className` 赋值。

### P1-7 控制台面板背景近乎全透明，场景与底层文字穿透

`#console-card` 用 `background: var(--color-surface)`，而 `--color-surface` 只有 `rgba(255,255,255,0.04)`（[style.css L14](../src/style.css#L14)），且未设置 `backdrop-filter`。

运行时截图可见两个后果：

1. 3D 网格线清晰穿透面板，直接压在矩阵数字与按钮文字上，读数时背景与前景互相干扰；
2. 固定在左下角的 `.hint`（层叠低于 `#console`）也被「透」上来，与展开面板里的「Y 向网格线」一行叠字。

改进方向：面板底色改为高不透明度的深色（如 `rgba(8,10,14,0.72)`）并叠加 `backdrop-filter: blur(12px)`，保留玻璃质感的同时恢复可读性。

## 四、P2 — 细节与体验

1. **`isTypingTarget` 靠函数提升**：定义在 [L450](../src/main.js#L450)，却被上方的 `ViewController.bindEvents` 先调用。能跑，但不符「先定义后使用」，移到类之前更稳。
2. **每帧 / 每次移动都新建对象**：`update()` 每帧 new 3 个 `Vector3`（[L424-431](../src/main.js#L424-L431)）；tooltip 的 mousemove 每次 `vectorList.map(...)` 新建数组（[L696](../src/main.js#L696)）。建议复用临时对象，避免后续加逻辑时形成每帧分配惯性。
3. **无自动约束机制**：仓库内没有 `eslint.config.*`、`.prettierrc*`、`.editorconfig`，`AGENTS.md` 全靠人读。建议加 ESLint（`no-unused-vars`、`prefer-const`、`eqeqeq`、`no-var`）+ Prettier（对齐现有 2 空格 / 单引号 / 分号），并补 `npm run lint`。均为 devDependencies，不破坏「零额外运行时依赖」。
4. **焦点样式不一致**：`#console-toggle` / `.section-toggle` / `.grid-toggle` 有自定义 `:focus-visible` 环，而 `#reset-btn`、`#add-vector-btn`、`.vector-del` 没有，只落到浏览器默认描边。
5. **动态控件缺可访问名称**：矩阵的 9 组 `number` / `range`、向量坐标的 3 个 `number` 都没有 `aria-label` 或关联 `<label>`，读屏只能听到「输入框」。
6. **向量坐标无范围约束**：矩阵元素有 `-3 ~ 3` 钳制，但向量坐标输入没有 `min/max`，可输入 `1e9` 让箭头飞出视野。**需要确认**：是有意放开，还是也应给一个范围？
7. **语义耦合**：向量坐标输入框的 `step` 复用 `CONFIG.matrixStep`（[L632](../src/main.js#L632)），把「矩阵元素步进」用在「向量坐标」上，建议独立为 `vectorCoordStep`。
8. **数值输入清空后不回填（运行时已确认）**：[L528-L532](../src/main.js#L528-L532) 对空串直接 `return`，矩阵内部仍保留旧值。实测：把 A[0][0] 设为 2 后清空输入框，`getMatrix()[0][0]` 仍为 2，输入框显示空白，失焦后依然为空——界面与内部状态不一致。
9. **`package.json` 缺 `"license": "MIT"`**（仓库已有 LICENSE 文件）。
10. **文档数字会漂移**：README 与 `AGENTS.md` 都写「约 563 KB」，本次构建实测 `566.29 kB`（553 KiB）。建议改为「约 550 KB+」或直接删掉具体数字。
11. **文档未记录已发布行为**：控制台「默认收起」、向量列表与网格线「各自独立折叠且默认收起」只写进了 CHANGELOG，README 与需求文档未提；而需求文档开头声明「内容与代码现状一致」。
12. **杂物**：`.screenshots/.tmp` 为空目录且未跟踪（git 不记录空目录），建议清理或写进 `.gitignore`。
13. **无触摸 / 移动端支持**：交互全靠 `mousedown` / `wheel` / `keydown`，未用 Pointer Events，触屏设备无法旋转。
14. **favicon 404**：`index.html` 未声明 favicon，dev / preview 下每次加载都会产生 1 条 `Failed to load resource: 404` 控制台错误——这是运行时**唯一**的报错。加一行 `<link rel="icon" href="data:,">` 即可消除，且不影响单文件离线打开。
15. **`.hint` 与展开后的面板重叠**：1280×800 下展开控制台后，卡片底边逼近视口底部，`.hint` 文案落在卡片区域内；叠加 P1-7 的透明问题后表现为文字压叠。
